# 门户首页与模块路由

| 地址 | 页面 |
| --- | --- |
| `/` | 公开门户首页 |
| `/jobs` | 岗位管理 |
| `/pipeline` | 求职进度 |
| `/schedule` | 日程安排 |
| `/interviews` | 面试题库 |

原来的工作区页面从 `app/page.tsx` 移至 `components/job-workspace.tsx`。
四个模块路由传入不同的 `initialView`，复用同一工作区，不复制数据处理逻辑。
工作区原有 Tab 切换仍保留原来的本地状态行为；点击左上品牌返回门户。
首页卡片和 CTA 通过普通链接进入对应路由，支持新标签页打开。
未登录用户进入模块后仍需登录；登录回跳地址保留所选模块。

## 首页资源与样式

- 首页结构：`app/page.tsx`。
- 首页专用样式：`app/portal.css`，全部使用 `portal-` 前缀，不覆盖工作区卡片。
- 模块地址：`lib/workspace-routes.ts`。
- 当前背景：`public/offer-city-hero-clean-v2.png`，基于用户提供的参考图整理出的无界面城市插画。
- 原参考图：`public/offer-city-hero.png`，保留不覆盖。

用户提供的文件是一张包含导航、文案、模块卡片的完整效果图。
新版通过内置 image_gen 整理出不带界面的城市背景，并将主楼放在画面右侧。
Hero 使用 `background-size: contain` 与 `background-position: right center`，
保留完整画面与楼顶、楼底；移动端在标题下方显示完整的 16:9 图片。
前景文字区域叠加轻渐变，页面文字、按钮、模块入口均为真实 HTML。
首页 slogan 为“求职有章法，好工作更容易”。底部重复开始区域已移除。
背景图的生成提示词见 `首页背景图生成说明.md`。

首页不展示虚构用户数量、节省时间比例或私人岗位数据。
入场、光晕与漂浮点使用纯 CSS；卡片 hover 使用上浮、发光与箭头反馈。
顶部导航使用半透明渐变与毛玻璃，光晕以 26 秒周期低频流动。
背景光晕以 22 秒周期变化，不缩放或裁切图片主体。
启用 `prefers-reduced-motion: reduce` 时关闭首页动画和位移。
不新增依赖，不改变数据库或 API。

PWA 的启动入口仍为 `/`，已有“岗位看板”快捷方式指向 `/jobs`。
Service Worker 缓存版本更新至 v6，以刷新修改后的 manifest。

## 本地运行

```powershell
npm.cmd run build
npm.cmd run local:preview
```

访问 `http://127.0.0.1:5173/`。修改源码后停止预览，重新构建并启动。
构建预览的 Vite 代理已关闭源码监听和自动依赖发现，避免扫描生成页面与本地缓存。
此配置仅作用于 `local:preview`，不影响 `npm run dev`。
