# 首页动态背景与统一导航

- 城市底图：`public/offer-city-panorama-v3.png`。使用内置 image_gen 编辑旧图，旧图保留。
- 宽幅城市图通过 `background-size: cover` 铺满 Hero，避免 contain 留下纯色边条。不同屏幕会适度裁切边缘。
- `components/portal-sky-elements.tsx`：四个独立信封和“目标达成”勾选徽章。信封复用 `components/offer-envelope.tsx`，与标题右侧插图一致，渐变 ID 各自独立。螺旋箭头与轨迹已移除；徽章采用 7 秒柔和呼吸光效，是装饰元素，不代表真实任务状态。系统开启减少动态效果时停止动画。
- 标题以 10 秒紫蓝流光突出重点，字距放宽至 0.025em；产品亮点文字桌面端 16px，顶部导航桌面端 16px。顶部重复的“进入岗位管理”按钮已移除。
- `components/site-navigation.tsx`：首页与工作区共用五项导航。工作区普通点击沿用原来的 setBoardView，保留筛选状态；新标签打开仍走现有模块路由。窄屏导航在顶部第二行横向滚动。
