# 首页背景图生成说明

- 方式：内置 `image_gen` 图片编辑工具；未调用 CLI/API，也未新增运行依赖。
- 输入：`public/offer-city-hero.png`，用户提供的完整页面效果图。
- 输出：`public/offer-city-hero-clean-v2.png`。
- 目的：去除图片内已有的界面，重建干净城市背景，使楼体偏右并完整显示。
