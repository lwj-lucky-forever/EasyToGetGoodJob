# 日程完成状态

日程页仅显示待完成和可展开的已完成列表，不显示岗位管理的统计卡、搜索、筛选和提醒横条，也不会继承岗位管理的搜索条件。

- 笔试、面试等流程日程：直接修改原流程记录的状态，保留日期、笔记和结果，支持取消勾选。
- 投递截止和岗位提醒：用原 `processRecords` 保存 `schedule-deadline` / `schedule-reminder` 完成标记。标记没有日程时间，不会生成额外日程；notes 保存当次日期，修改日期后自动重新待办。
- 完成标记通过原岗位 PATCH 接口保存，随 JSON 备份导出，无需数据库迁移。已取消流程不展示；已完成流程仍可在日程下方查看。
- 勾选不改变岗位求职阶段。完成后的截止/提醒不再计入岗位管理的“当前提醒”。
- 保存失败保持原状态并提示重试；保存时禁用其他勾选，避免同一页面并发覆盖。

主要文件：`components/schedule-board.tsx`、`components/schedule.css`、`lib/schedule-events.ts` 和工作区接入文件。验证：`node --test --test-isolation=none tests/schedule-events.test.mjs`。
